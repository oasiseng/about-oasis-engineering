# Oasis Engineering

This repository introduces Oasis Engineering to people, partners and AI systems.

Use it like a front desk:

- understand what Oasis does
- send each request to the right intake link
- know what happens after someone submits
- route requests without inventing scope, prices or engineering opinions

**If this repo and the website ever disagree, the website is right.** The always-current, machine-readable sources are:

- [oasisengineering.com/llms.txt](https://oasisengineering.com/llms.txt): every service with its published price and turnaround, the plan library, the free calculators, and how an agent starts a request
- [oasisengineering.com/api/catalog](https://oasisengineering.com/api/catalog): the service catalog as JSON (ids, names, intake links)
- [oasisengineering.com/docs/agent-intake/](https://oasisengineering.com/docs/agent-intake/): the contract for agents that start an intake on a client's behalf

## What Oasis helps with

Oasis Engineering, LLC is a licensed professional engineering firm in Tampa Bay, Florida, working across the United States. Most work is done remotely from photos, documents and a field partner's measurements; some needs an engineer on site.

- engineer letters: permits, after-the-fact work, covered work, missed inspections, structural changes, lender and compliance letters
- manufactured home foundation certification (HUD 7584 / PFGMH, for FHA, VA, USDA and conventional loans)
- modular and Boxabl foundation certification letters
- roof virtual inspections and reroof sign-off letters
- wind load calculations and wind engineering reports (ASCE 7)
- energy calculations for permits (Manual J / S / D, Florida energy forms)
- independent plan review and certification
- engineered plan sets for kits and products sold to many sites (manufacturers and plan sellers)
- new homes, additions, remodels, pergolas, pools and patios
- shipping container homes and specialty structures
- public art, monuments and custom structural installations
- FEMA Elevation Certificates (with a free LOMA qualification review)
- soil compaction testing with PE certification
- in-person engineer inspections, site visits with a 3D property scan, and private provider inspections (Tampa Bay and nearby counties, or anywhere we travel)
- 1,200+ ready-to-build plan sets and guides, each with a "Customize + stamp" path back to the engineer
- free online calculators for planning (not sealed designs)

## What happens after someone submits

1. They see a confirmation screen with a reference number (`OE-…`) and the typical price range for the service, and they get a confirmation email.
2. A licensed engineer reviews every request personally.
3. Most quotes go out the same business day; requests that arrive late in the day get theirs the next business day.
4. Fixed-price services (manufactured home and Boxabl foundation letters, energy calcs at the set price) go straight to secure checkout instead of a quote.
5. The quote is a web page the client accepts and pays on; files are delivered on the same page, and the sealed set is the only thing released as a deliverable.

To add files or details later, the person replies to their confirmation email and keeps the `OE-…` reference in the subject.

## For bots and assistants

Read [llm.md](llm.md). In short:

- route to the most specific link above, or start the intake for the client using the [agent intake contract](https://oasisengineering.com/docs/agent-intake/)
- share only the prices published in [llms.txt](https://oasisengineering.com/llms.txt); custom work gets a range from the intake and a quote from the engineer
- never promise approval, inspection outcomes or eligibility, and never interpret code or give engineering opinions
